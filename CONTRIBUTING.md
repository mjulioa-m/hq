# Contribuir

Un cambio nace en una issue pública. El pull request enlaza esa issue. Un tema por pull request.

No incluyas `.env`, claves, copias de bases ni datos reales de nadie.

La interfaz sigue en español. Los identificadores del código, en inglés.

Antes de abrir el pull request:

```bash
npx tsc --noEmit
```

El build y el lint de este repo usan Node 24.
